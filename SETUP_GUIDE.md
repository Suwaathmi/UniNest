# Setup Guide for UniNest

## Introduction
Welcome to the UniNest project! This guide will help you set up and deploy the application.

## Prerequisites
- Git
- Node.js (version x.x.x)
- npm (version x.x.x)

## Cloning the Repository
To clone the repository, run the following command in your terminal:
```bash
git clone https://github.com/Suwaathmi/UniNest.git
```

## Installing Dependencies
Navigate to the project directory and install the dependencies:
```bash
cd UniNest
npm install
```

## Configuration
Ensure you set up your environment configuration as needed:
- Copy `.env.example` to `.env` and fill in the required values.

## Running the Application
You can start the application in development mode using:
```bash
npm start
```

## Deployment
For production deployment, use:
```bash
npm run build
npm start
```
- Follow hosting provider specific instructions for deploying your built application.

## Troubleshooting
If you encounter any issues, check the following:
- Ensure all dependencies are installed.
- Verify your environment variables are set correctly.

## Conclusion
Thank you for using UniNest! If you have any questions, feel free to raise an issue in the repository or consult the community.
